# 🍴 My Diploma Project - Food Ordering System

## 📌 About the Project

This is an Online Food Ordering System developed as my Diploma project.

The project allows users to browse food items, add items to the cart, place orders, and view their order history.

## 🚀 Features

- 🔐 User Login
- 🍔 Food Menu
- 🔍 Food Search
- 🛒 Add to Cart
- ➕ Increase / Decrease Quantity
- 🗑️ Remove Items from Cart
- 📦 Order History
- ⭐ Food Ratings
- 💳 Payment Selection
- 🌙 Dark Mode
- 👨‍💼 Admin Panel
- 💬 Feedback

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## 🎯 Project Purpose

This project was developed to understand web development and create a simple real-world online food ordering application.
